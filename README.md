# AWS S3 Static Website Hosting

## Objective

To host a static website using Amazon S3, upload website files, configure public access permissions, and make the website accessible through the S3 website endpoint.

## Services Used

* Amazon S3 (Simple Storage Service)
* AWS Management Console

## Steps Performed

1. Created an S3 bucket in AWS.
2. Developed a static website using HTML.
3. Uploaded website files to the bucket.
4. Enabled Static Website Hosting.
5. Configured bucket policy and public access permissions.
6. Accessed the website through the S3 website endpoint URL.

## Result

Successfully hosted a static website on Amazon S3 by uploading website files, enabling static website hosting, configuring public access, and verifying website accessibility through the generated endpoint URL.
